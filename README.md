# Clonal Hematopoiesis in 3D

Interactive 3D views of a bibliometric analysis of clonal hematopoiesis research (2,293 Web of Science core records, 2014–2026).

- [Keyword Star Map](keyword.html): 146 author keywords from the VOSviewer map: star map, terrain, burst and nebula views.
- [Co-citation Star Map](cocitation.html): The 40 most-cited references and their 638 co-citation links, in the same four views.
- [Collaboration Globe](globe.html): Papers and co-authorship between 76 countries, with a filter for arc strength.

Generated by scripts 34–37 of the analysis project; open `index.html` to start.
